# 🎨 NewsCard Maker — Social Media News Headline Banner Generator

[![Next.js](https://img.shields.io/badge/Platform-Web_Application-black?style=for-the-badge&logo=next.js)](https://nextjs.org/)
[![TypeScript](https://img.shields.io/badge/Language-TypeScript_|_JavaScript-blue?style=for-the-badge)](https://www.typescriptlang.org/)
[![License](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)](LICENSE)

A graphic design utility built for journalists and media managers to generate branded, social-media-ready news photo cards in seconds.

---

## 🌟 Key Features

- **Dynamic Layout Templates**: Select from breaking news, quote cards, statistics, and photo highlights.
- **One-Click Image Export**: Export high-resolution PNG/JPEG graphics formatted for Facebook, Twitter, and Instagram.
- **Branding & Watermarks**: Automatically applies publisher logos, reporter bylines, and date stamps.

---

## 🛠️ Technology Stack

- **Framework**: Next.js, React, Canvas API

---

## 🚀 Getting Started

```bash
# 1. Clone repository
git clone https://github.com/morshedkoli/newscardmaker.git

# 2. Install dependencies
npm install

# 3. Launch application
npm run dev
```
